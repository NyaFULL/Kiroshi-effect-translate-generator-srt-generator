# 👁️ Cyberpunk 2077 Kiroshi HUD .SRT Generator (Left-Aligned Edition)

Автономный локальный веб-генератор субтитров, воссоздающий оригинальный визуальный эффект дешифровки и перевода из военного импланта **Kiroshi HUD** в игре *Cyberpunk 2077*. Специально разработан и оптимизирован для импорта в видеоредактор **CapCut**.

## 🚀 В чём уникальность этого генератора?

Этот инструмент разрабатывался и полировался на протяжении месяца, чтобы полностью повторить графические алгоритмы из игры. В отличие от обычных скриптов, которые заставляют строку хаотично прыгать и сжиматься, данный генератор использует **оригинальную физику левого сопоставления (Left Alignment)**, принятую в интерфейсах CD Projekt RED.

### 🔥 Ключевые фичи:
* **Эффект «Ножниц» (Мгновенное отсечение):** Лишний иностранный остаток не стирается по буквам в пустоту — он полностью удаляется из кода строго в один кадр, одновременно с открытием последней буквы перевода.
* **Истинное левое сопоставление:** Текст изначально привязан к левому краю. Буквы перевода выходят строго на своих финальных пиксельных позициях (ячейка в ячейку поверх иностранного текста), вообще не сдвигая строку субтитров.
* **Автономность слоев:** Если понятное слово длиннее иностранного — перевод спокойно продолжает дописываться дальше в одиночку до победного конца, не обрывая анимацию. Буквы никогда не пишутся «в пустоту».
* **Цифровая HUD-вибрация:** Во время дешифровки правый край строки мелко и чарующе дребезжит на месте за счет покачивания пиксельного баланса прозрачным маркером (`\u2003`). В финале вибрация мгновенно отключается, намертво фиксируя готовый текст.

## ⚠️ Важное техническое ограничение CapCut

В процессе разработки было выявлено жесткое ограничение мобильного и ПК движка **CapCut**: видеоредактор физически не способен корректно обрабатывать и считывать кадры субтитров длительностью **меньше 0.2 секунд (200 мс)**. 

Если выставить шаг анимации в 0.1 сек или 0.05 сек, CapCut начнет слепо склеивать реплики, пропускать буквы и ломать таймлайн. 
> **Решение:** В генераторе по умолчанию выставлен режим **«Очень медленно (0.2 сек)»**. Настоятельно рекомендуется использовать именно его — это гарантирует 100% стабильную, плавную и монолитную анимацию кадра без технических багов при импорте.

## 🛠️ Стек технологий
* **Frontend:** Чистый HTML5 / CSS3 (Стильный киберпанк-интерфейс в тёмных тонах).
* **Core:** Vanilla JS (ES6+). Полностью автономен, работает без бэкенда, внешних библиотек и интернета.
* **Unicode Safe:** Строки обрабатываются через `Array.from()`, что защищает от разрушения сложные символы (иероглифы, эмодзи, диакритику).

## 🎬 Инструкция по применению
1. Откройте файл `generator_srt.html` в любом браузере.
2. Введите иностранный текст и перевод.
3. Оставьте скорость по умолчанию (**Очень медленно (0.2 сек)**) для идеальной совместимости с CapCut.
4. Нажмите **«Скачать .SRT файл»**.
5. Импортируйте полученный файл субтитров в **CapCut**.
6. **ОБЯЗАТЕЛЬНОЕ ДЕЙСТВИЕ:** Выделите дорожку субтитров, перейдите в параметры текста и выберите **«Выравнивание по левому краю» (Align Left)**. После этого мышкой перетащите весь блок в нужное место на экране. 

*Левая граница зафиксируется намертво, буквы перевода будут выходить строго на своих местах, а иностранный кончик отрубится в один миг без единого дёрганья строки!*
