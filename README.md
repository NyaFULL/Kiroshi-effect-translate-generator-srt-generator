# 👁️ Cyberpunk 2077 Kiroshi HUD .SRT Generator

Автономный локальный веб-генератор субтитров, воссоздающий оригинальный визуальный эффект дешифровки и перевода из импланта **Kiroshi HUD** в игре *Cyberpunk 2077*. Специально оптимизирован для идеального импорта в видеоредактор **CapCut**.

## 🚀 В чём уникальность этого генератора?

Обычные генераторы субтитров заменяют символы "вслепую", из-за чего в CapCut текст постоянно прыгает по ширине, дёргается и ломает геометрию кадра. Этот инструмент разрабатывался и полировался на протяжении месяца, чтобы полностью решить проблемы пропорциональных шрифтов и физики видеоредакторов.

### 🔥 Ключевые фичи:
* **Эффект «Ножниц» (Мгновенное отсечение):** Лишний иностранный остаток не стирается уныло по буквам в пустоту — он отрубается строго в один кадр, одновременно с открытием последней буквы перевода.
* **Идеальный нулевой сдвиг (Фиксация центра):** Понятное слово изначально пишется строго на своих вечных пиксельных координатах. В момент отсечения хвоста робот на лету замеряет его ширину на скрытой линейке и заменяет невидимыми Юникод-блоками (`\u2003` и `\u2002`). Текст застывает как вкопанный ровно по центру.
* **Синхронный накат:** Перевод плавно вытесняет иностранный текст ячейка в ячейку в строгом темпе (0.2 сек по умолчанию).
* **Автономность слоев:** Если понятное слово длиннее — оно спокойно продолжит дописываться дальше, даже если иностранное слово уже полностью скрылось. Буквы никогда не пишутся «в одиночестве».
* **Цифровая HUD-вибрация:** Во время дешифровки строка мелко и чарующе дрожжит на месте за счет покачивания пиксельного баланса невидимыми символами. В финале вибрация мгновенно отключается, фиксируя статику.

## 🛠️ Стек технологий
* **Frontend:** Чистый HTML5 / CSS3 (Стильный киберпанк-интерфейс в тёмных тонах).
* **Core:** Vanilla JS (ES6+). Полностью автономен, работает без бэкенда, библиотек и интернета.
* **Unicode Safe:** Строки обрабатываются через `Array.from()`, что защищает от разрушения сложные символы (иероглифы, эмодзи, диакритику).

## 🎬 Инструкция для CapCut
1. Откройте файл `generator_srt.html` в любом браузере.
2. Введите иностранный текст и перевод, выберите скорость и нажмите **«Скачать .SRT файл»**.
3. Импортируйте полученный файл субтитров в **CapCut**.
4. **Важно:** Для раскрытия эффекта на 100% оставьте выравнивание текста **по центру (Align Center)** и примените любой шрифт. Текст будет плавно ехать, вибрировать и монолитно застынет в финале!
